# Admin stack

- **Run**: Node 24. `pnpm dev` (port 3001), `pnpm storybook` (6006), `pnpm build-storybook`.
  Checks: `pnpm lint && pnpm typecheck && pnpm test && pnpm build`.
- **Framework**: Next 16 App Router, React 19, Tailwind 4, shadcn `base-nova` on Base UI.
  `next.config.ts` sets `experimental.rootParams` because next-i18next's server entry needs it.
- **Design**: dark only (`<html class="dark">`), black and white, one red (`destructive`).
  Fonts are self-hosted with fontsource: Geist for Latin, Vazirmatn for Persian.
- **Language**: next-i18next in cookie mode, cookie `app-lang`, default `en`, no locale in the
  URL. `applyLanguage` sets the cookie and `<html lang dir>`; Persian is `rtl`.
- **Data**: SDK generated by hey-api from the API's OpenAPI (`pnpm generate:api`, never
  hand-edited), react-query for reads, react-hook-form with Zod for forms, nuqs for URL state.
- **Editor**: Tiptap with `@tiptap/markdown`. A post body is stored as a Markdown string;
  each block has `dir="auto"`. The Source toggle edits the same Markdown as plain text.
- **Tests**: Vitest, jsdom, Testing Library. `vitest.config.ts` inlines `next-i18next`;
  tests that mock `next/navigation` include `useParams`.
- **Stories**: Storybook 10 with `@storybook/nextjs-vite` and the a11y addon; the toolbar
  switches English/Persian (`dir`, `lang`).
